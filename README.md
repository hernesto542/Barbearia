# Barbearia

Sistema de agendamento para barbearias desenvolvido com HTML, CSS e JavaScript puro.

O projeto permite que clientes realizem agendamentos online de forma simples e prática, enquanto o barbeiro consegue visualizar, editar e excluir horários através da página de gerenciamento.

---

## 🚀 Funcionalidades

- Agendamento de clientes
- Seleção de múltiplos serviços
- Bloqueio automático de horários ocupados
- Bloqueio de dias totalmente lotados
- Edição de agendamentos
- Exclusão de agendamentos
- Validação personalizada de formulário
- Feedback visual de ações
- Interface responsiva
- Integração com WhatsApp
- Integração com Google Maps

---

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Flatpickr
- Typed.js
- MockAPI

---

## 📅 Regras de Agendamento

- Horários já utilizados ficam indisponíveis
- Dias completamente preenchidos ficam bloqueados no calendário
- O usuário precisa selecionar uma data antes de escolher um horário
- É obrigatório selecionar pelo menos um serviço
